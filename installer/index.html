Flash risk and backup responsibility

Flashing firmware overwrites device contents. Power loss, unplugging, choosing the wrong model, or using incompatible firmware can erase settings or leave the device unable to boot.

This installer does not automatically back up existing firmware, Wi-Fi credentials, or widget settings. Back up or record anything you need to keep, and prepare your own recovery path before you start.

This tool is provided as-is. To the extent permitted by law, risk and responsibility for flashing, data loss, and device recovery remain with the user.

This browser does not support Web Serial. Use desktop Chrome or Edge.

Before you install

  • Use a data-capable USB cable, not charge-only.
  • Close other apps that may hold the serial port.
  • Confirm the device model matches the selection above.

How it works

The whole install stays in the browser and usually takes a few minutes.

  1. 1

    Connect the device

    Use a USB data cable and keep the device powered steadily.

  2. 2

    Authorize the port

    Click “Connect device and install”, then choose the new USB serial port.

  3. 3

    Finish writing

    Do not unplug or close the tab. The device restarts when complete.

First-boot setup

On first boot the device creates a setup Wi-Fi network. Phones and computers do not need an extra app.

After normal Wi-Fi is configured, press Volume Up to open the on-device English settings page on the current network. The display shows the local URL and a QR code with a session path.

Wi-Fi name TransitInk-xxxx
Wi-Fi password Shown on the device screen
Setup URL http://192.168.4.1/

Complete these items in settings

  • Connect to Wi-Fi Enter the network name and password you use day to day.
  • Arrange the dashboard Pick up to four TTC stops, reorder them, or disable unused slots.
  • Power options Optionally enable sleep and a daily awake window.
